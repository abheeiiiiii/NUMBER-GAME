🎮 Play With Numbers – Puzzle Game

Play With Numbers is an interactive, level-based number puzzle game built using HTML, CSS, and JavaScript.
The game challenges players to clear a grid by intelligently pairing numbers using logical rules, improving concentration and pattern recognition.

📌 Game Overview

The goal of the game is to clear all numbers from the grid by forming valid pairs.
Players progress through 50 progressively challenging levels, earn coins, use hints, and manage time efficiently.

🧠 How to Play
✅ Valid Pairs

You can remove two numbers if:

Both numbers are equal (e.g., 7 & 7)

The sum of the numbers is 10 (e.g., 2 & 8)

🔗 Valid Connections

A pair can be connected if the path between them is clear:

Horizontally

Vertically

Diagonally

Line-by-line (end of one row to the start of the next)
